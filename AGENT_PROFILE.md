# Mori Together

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

Turn “we should hang out sometime” into a plan you both say yes to.

Create a shared plan, invite a friend in a separate direct conversation, enter
your preferences, search activities, and separately approve a specific proposal.
Start with `new YourName` or `help`. Pilot cities: Berkeley and San Francisco.
Uses Agent Chat Protocol, ASI:One forms/carousels/review cards, Ticketmaster, and Google Maps place discovery.

In a group channel, @mention Mori Together in every message meant for it. In our channel tests, Mori received
only messages mentioning it. Do not assume it can read other messages or shared links.
Assistants relaying for a user should send Mori's commands (`status`, `search`, `edit`)
or the user's own words with the mention, not a summary of the chat.

This prototype distinguishes conversation sessions, not verified human identities.
Never paste sensitive chat histories. Preferences are visible to your partner.
No ticket purchase or reservation. `forget` clears your preferences; the creator
can `delete` the shared plan. Live inventory and final fees require checking.
